# SP3149609_Padaria
Projeto para a disciplina de Laboratório de Programação 2

# Entidades
No sistema da padaria serão criadas as entidades Cliente, Funcionário e Produtos.

Cliente
----------------------------------------
- id: int
- nome: String
- telefone: String
- cargo: String
----------------------------------------
- salario: double
+ incluir(): void
+ alterar(): void
+ excluir(): void 
+ listar(): List


Produto
----------------------------------------
- id: int
- nome: String
- preco: double
- quantidade: Int
----------------------------------------
- categoria: String
+ incluir(): void
+ alterar(): void
+ excluir(): void 
+ listar(): List

Funcionário
----------------------------------------
 - id: int
- nome: String
- telefone: String
- email: String
- endereco: String
----------------------------------------
+ incluir(): void
+ alterar(): void
+ excluir(): void 
+ listar(): List
  
# Tecnologias 
JSP, Gson, JSON e o servidor usado (Tomcat).
